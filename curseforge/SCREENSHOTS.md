# Screenshot guide

CurseForge shows the first screenshot as the cover, so take them in this order. Aim for 1920x1080, a clean HUD and no debug screen (F3 off).
Press **F2** to capture. Files land in `.minecraft/screenshots` (in the dev client: `fabric/run/screenshots`).

## Before you start
- Use a **creative or op test world**, set the time to day (`/time set day`) and the weather to clear. Use night only for the gate shots.
- Turn the **GUI scale** to 2 or 3 so the skill wheel and status window read well when shrunk.
- Set render distance to 16+ and, if you can, add a shader pack for the outdoor shots. The dungeon shots look good without one.
- Set the Field of View to about 80. Hide the hand with F1 for the scenery shots only. Keep the HUD for the combat shots.
- The dev client name is Player896. A short, clean name looks better, so launch with your own account for the final shots.
- Because players cannot build in the Spire by default, you only need protection off if you want to stage something there (`protectFromCreative` in the dungeon config).

## Cover and must-haves (take these first)

| # | Shot | How to set it up | Tip |
|---|---|---|---|
| 1 | **Gate at dusk** | `/gatebound gate spawn c` in an open field at night. Wait about 20 seconds so monsters leak out. | Stand back so the label, vortex and a few mobs fit. This is the cover. |
| 2 | **Awakening screen** | `/gatebound class reset`, then `/gatebound awaken`. | Take the class choice with the five cards visible. |
| 3 | **Skill wheel mid-fight** | Hold Z with a few mobs near you at level 30+ (`/gatebound level set 40`). | Pick a class with colourful effects, such as Mage. |
| 4 | **Spell effect** | `/gatebound element grant fire`, then cast a high-level spell. Repeat for ice and lightning. | Aim for the moment of impact. |
| 5 | **A Mage form** | `/gatebound level set 100`, pick an element, cast the level 100 form. | Third person (F5) so the transformation shows. |
| 6 | **Guardian arena** | Enter a gate (`/gatebound gate spawn b`) and walk to the end of the dungeon. | Take it just as you enter, with the boss in view. |
| 7 | **The tower from outside** | Go to the overworld landmark, about 70 blocks east of spawn. | Golden hour or a shader helps. |

## Combat
- 8. **Parry and finisher**: fight a mob and parry its heavy hit. Use `/gatebound combat debug` if you want the timing visible. Skip debug for the final shot.
- 9. **Dodge**: a Rogue dodging a telegraphed attack.
- 10. **Rogue shadow**: Vanish, or inside a Shadow Meld.
- 11. **Ranger aiming**: the greyscale focus effect while drawing a bow, with enemies in the distance.
- 12. **Grapple swing**: crouch + right-click with the Compound Bow in a Spire cave floor.
- 13. **Quiver on the back**: a Ranger in third person with the quiver visible.

## Spire and dungeons
- 14. **Status window** (Tab) with spent stat points.
- 15. **Tower hall**: carpet, pillars, dais, and the two NPCs (Skill Broker and Scholar). `/gatebound npc spawn broker` if they are missing.
- 16. **One floor from each theme**: Catacombs, Mossy Caverns, Flooded Halls, Lava Halls, Ashen Caverns, Void Sanctum. Wide shots from a doorway work best.
- 17. **Rest floor** with the water and campfires.
- 18. **Mana crystals** glowing against a dungeon wall.
- 19. **Collapse countdown**: kill a guardian and take a shot with the chat warning and the timer.
- 20. **A custom monster**: Crypt Lord, Ashen Colossus or Void Sovereign, up close.

## Echoes
- 21. **Soul body** after a Summoner kill, with the countdown name and light column.
- 22. **Echo screen** (H) with several groups and a found gate listed.
- 23. **A flying Echo being ridden** over a gate. `/gatebound echo add minecraft:phantom` for a quick test.
- 24. **A group of Echoes** fighting beside you.

## Finishing
- Pick the **best 8 to 12**. CurseForge shows the first few most prominently.
- Trim anything cluttered, with a clean HUD and no chat except where the chat is the point.
- Put the cover shot (gate at dusk) first, then a class or combat shot, then the tower.
- Add a short caption to each one, for example "Break open a rank-S gate" or "Bind the monsters you defeat".
- A **GIF** of the skill wheel, a parry, or the grapple works well in the description.
